# Syrve Menu

Сайт для перегляду номенклатури Syrve в браузері — замість ланцюжка запитів у Postman.

**Робоча версія:** https://syrve-viewer-production.up.railway.app

## Що вміє

1. Обрати спосіб входу (перемикач угорі):
   - **V1** — `apiLogin` (`/api/1/access_token`);
   - **V2** — `apiKey` + застосунок (`/api/v2/access_token` з `apiKey`, `appId`, `clientSecret`). Застосунок можна взяти з налаштувань сервера (тоді `appId` і `clientSecret` вводити не треба) або ввести вручну.
2. **Отримати організації** — сервер сам отримує токен і показує список організацій закладу (з копіюванням id).
3. У блоці **Що показати** обрати джерело:
   - **Номенклатура** — `/api/1/nomenclature`;
   - будь-яке **зовнішнє меню** зі списку `/api/2/menu` — тоді для обраної організації завантажується `/api/2/menu/by_id` (`version: 3`). Якщо в акаунті є цінові категорії, зʼявиться вибір цінової категорії.
4. Клікнути на організацію → праворуч зʼявляються дані у вигляді JSON-дерева. Можна перемикати організації і джерела — дані перезавантажуються.
5. У шапці — кількість елементів у кожному масиві верхнього рівня, `revision`, **кількість рядків** (як у Postman у форматі Pretty) і розмір відповіді.
6. Пошук по всьому JSON (назви, id, артикули): клік по результату розгортає дерево до потрібного місця.
7. **Копіювати** / **Завантажити** JSON файлом; кнопки **JSON** — сирі відповіді `/organizations` і `/api/2/menu`.

### Перевірка apiLogin

- Робочий ключ: зелена плашка `✓ apiLogin активний · організацій: N`.
- Помилка: код + пояснення українською + оригінальний текст Syrve + `correlationId` (для підтримки Syrve).

| Код | Що означає |
|-----|------------|
| 401 | apiLogin не знайдено або він вимкнений |
| 423 | Ліцензія Cloud API для цього apiLogin закінчилась |
| 429 | Забагато запитів — спробуйте трохи пізніше |
| 5xx | Syrve тимчасово недоступний |

## Як влаштовано

```
Браузер  →  /api/organizations  →  Syrve /api/1/access_token або /api/v2/access_token + /api/1/organizations
Браузер  →  /api/nomenclature   →  Syrve /api/1/nomenclature
Браузер  →  /api/menus          →  Syrve /api/2/menu (без тіла)
Браузер  →  /api/menu           →  Syrve /api/2/menu/by_id { externalMenuId, organizationIds: [id], version: 3 }
```

Усі запити після входу йдуть з тим самим токеном.

- `server.js` — сервер на Node.js **без залежностей**: віддає сторінку і проксіює запити до Syrve (обходить CORS, токен не потрапляє в браузер).
- `public/index.html` — уся сторінка (HTML + CSS + JS в одному файлі).
- Токен кешується в памʼяті сервера на ~50 хв; якщо Syrve відповість 401, токен оновлюється автоматично.
- `apiLogin` / `apiKey` на сервері не зберігаються. Браузер памʼятає останні 10 введених значень для підказки в полі вводу; `appId` / `clientSecret`, введені вручну, — лише в цьому браузері.
- Великі відповіді (перевірено на 1,2 млн рядків / 18 МБ) відкриваються за долі секунди: дерево малюється порціями по 200 елементів, відповідь стискається gzip.
- Сайт без пароля: відкрити може будь-хто, хто знає адресу, але без власного `apiLogin` нічого не побачить.

## Деплой

Railway: проєкт **brilliant-celebration** → сервіс **syrve-viewer**, підключений до цього репозиторію (гілка `main`).

**Кожен push у `main` автоматично деплоїться** — за 1–2 хвилини зміни на сайті.

Ручний деплой з локальної папки (якщо потрібно):

```bash
railway up --service syrve-viewer
```

Змінні оточення (необовʼязкові):

| Змінна      | За замовчуванням                  | Для чого                  |
|-------------|-----------------------------------|---------------------------|
| `SYRVE_API` | `https://api-eu.syrve.live/api/1` | інший регіон/сервер Syrve (шляхи `/api/v2` і `/api/2` виводяться з нього) |
| `SYRVE_APP_ID` | —                              | `appId` застосунку для V2 (щоб не вводити вручну) |
| `SYRVE_CLIENT_SECRET` | —                       | `clientSecret` цього застосунку (назовні не віддається) |
| `SYRVE_APP_NAME` | `Застосунок сервера`         | назва застосунку у виборі на сторінці |
| `PORT`      | задає Railway                     | порт сервера              |

## Запуск локально

Потрібен Node.js 22.

```bash
node server.js
```
