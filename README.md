# Syrve Номенклатура

Робоча версія: https://syrve-viewer-production.up.railway.app (Railway, проєкт `brilliant-celebration`, сервіс `syrve-viewer`).

Сайт для перегляду номенклатури Syrve в браузері:
ввести `apiLogin` → отримати список організацій → клікнути на організацію → переглянути JSON номенклатури.

- Сервер сам отримує токен (і оновлює його, коли той закінчується).
- JSON показується деревом: розгортання вузлів, пошук по ключах і значеннях, копіювання, завантаження файлом.
- Без залежностей: потрібен лише Node.js 18+.

## Запуск локально

```bash
node server.js
```

Відкрити http://localhost:3000

## Деплой на Railway

1. Створити репозиторій на GitHub і запушити туди цю папку (`syrve-viewer`).
2. На https://railway.com → **New Project** → **Deploy from GitHub repo** → обрати репозиторій.
3. Railway сам визначить Node.js і запустить `npm start`.
4. У сервісі: **Settings → Networking → Generate Domain**, щоб отримати адресу сайту.

Змінні оточення (необовʼязкові):

| Змінна      | За замовчуванням                    | Для чого                       |
|-------------|-------------------------------------|--------------------------------|
| `SYRVE_API` | `https://api-eu.syrve.live/api/1`   | інший регіон/сервер Syrve      |
| `PORT`      | задає Railway                       | порт сервера                   |

## Як це працює

```
Браузер  →  /api/organizations  →  Syrve /access_token + /organizations
Браузер  →  /api/nomenclature   →  Syrve /nomenclature (з тим самим токеном)
```

`apiLogin` нікуди не зберігається на сервері (тільки токен у памʼяті на ~50 хв).
У браузері останні 10 введених `apiLogin` запамʼятовуються для підказки в полі вводу.

> Сайт без пароля: будь-хто, хто знає адресу, може ним користуватися (але лише зі своїм `apiLogin`).
