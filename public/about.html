Було і стало

Один і той самий результат

Сайт робить ті самі запити до Syrve, що й Postman, у тому самому порядку. Різниця в тому, хто копіює токен і id між ними.

Postman 4 запити вручну

  1. POST/api/v2/access_tokenapiKey, appId, clientSecret → копіюєте token
  2. POST/api/2/menuBearer token → копіюєте id меню
  3. POST/api/1/organizationsBearer token → копіюєте id організації
  4. POST/api/2/menu/by_idвставляєте externalMenuId, organizationIds, version 3

Токен живе близько години, потім усе спочатку.

Syrve Viewer 3 кліки

  1. 1Вставити apiLogin (V1) або apiKey (V2) і натиснути Отримати організації.
  2. 2У блоці Що показати обрати номенклатуру або потрібне зовнішнє меню.
  3. 3Клікнути на організацію. Дані відкриються праворуч.

Токен сайт отримує і оновлює сам. Організації й меню можна перемикати без повторного входу.

Що вміє

Усе, за чим ходили в Postman

/api/1 · /api/v2/access_token

Вхід через V1 і V2

V1 приймає apiLogin. Для V2 достатньо apiKey: appId і clientSecret застосунку вже збережені на сервері, за потреби їх можна ввести вручну.

/api/1/nomenclature

Номенклатура

Групи, товари, категорії, розміри і revision, як у відповіді Syrve. Клік на іншу організацію одразу перезавантажує дані.

/api/2/menu/by_id

Зовнішні меню

Список меню підтягується сам. Обираєте меню й організацію, version 3 підставляється автоматично. Цінова категорія з'являється, якщо вона є в акаунті.

пошук

Дерево і пошук

Пошук іде по ключах і значеннях: назва, id, артикул. Біля збігу видно, до якого товару він належить, а клік розгортає дерево до цього місця.

рядків · розмір

Лічильники

Кількість елементів у кожному масиві, рядків як у Postman у режимі Pretty, і розмір відповіді. Зручно звіряти з тим, що бачить клієнт.

копіювати · завантажити

JSON у один клік

Скопіювати всю відповідь або завантажити файлом. Окремі кнопки JSON показують сирі відповіді організацій і списку меню.

Перевірка ключа

Видно, чи ключ живий

Сайт зручно відкривати, навіть коли потрібно просто перевірити ключ клієнта. Якщо Syrve відмовив, видно код, пояснення українською, оригінальний текст і correlationId для підтримки Syrve.

КодЩо означаєЩо робити
200Ключ активнийЗелена плашка з кількістю організацій.
401apiLogin не знайдено або вимкненийПеревірити ключ у клієнта. Для V2: apiKey, appId або clientSecret.
423Ліцензія Cloud API закінчиласьКлюч правильний, але клієнту потрібно продовжити ліцензію в Syrve.
429Забагато запитівПочекати хвилину і повторити.
5xxSyrve тимчасово недоступнийПовторити пізніше. Якщо не минає, передати correlationId у Syrve.
Біля кожної помилки є кнопка, щоб скопіювати correlationId.
